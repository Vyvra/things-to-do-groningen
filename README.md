# Things to do in Groningen

A friendly one-page guide to free, drop-in and worth-your-time things to do
in Groningen, Netherlands — sport, tours, workshops, games, food, culture and
quiet corners.

**Live site:** <https://vyvra.github.io/things-to-do-groningen/>

Researched August 2026. Built as plain HTML/CSS/JS — no build step, no
frameworks. Content in `index.html`, styling in `style.css`, a little
progressive-enhancement JS in `script.js`.
